# Isolated Footing Reinforcement Design (ACI 318)

Python script for automated design and reinforcement verification of rectangular isolated footings subjected to concentric axial load, based on the **ACI 318** standard criteria.

---

## 📋 Overview

This script performs structural analysis and sizing of main and secondary reinforcement steel for a central isolated footing. It sequentially evaluates serviceability and ultimate limit state conditions required by current codes, including:

1. **One-way shear verification** (flexural shear) along both orthogonal directions.
2. **Two-way shear verification (punching shear)** assuming an interior column ($\alpha_s = 40$) and code-specified limits.
3. **Ultimate bending moment calculation** and required steel area ($A_s$) per meter width.
4. **Minimum reinforcement determination** ($\rho_{\min} = 0.0018$) and optimal bar spacing with practical rounding.
5. **Development length and $90^\circ$ standard hook checks** due to geometric cantilever constraints.

## 🔬 Theoretical & Code Basis (ACI 318)

The script enforces the following structural safety checks:

1. **One-Way Shear:**
   Evaluated at critical sections located at distance $d$ from the column face in both directions. Nominal concrete shear strength is calculated as:
   $$V_c = 0.53 \lambda \sqrt{f'_c} b_w d$$
   If ultimate shear force $V_{ua}$ exceeds design strength $\phi V_c$, the script halts execution and issues a warning to increase total depth $C$.

2. **Two-Way Shear (Punching Shear):**
   Evaluated along a critical perimeter $b_0$ located at $d/2$ from the column faces. Design shear strength is defined as the minimum value among three ACI 318 code expressions:
   * $V_{c1} = \phi \times 0.53 \left(1 + \frac{2}{\beta_c}\right) \sqrt{f'_c} b_0 d$
   * $V_{c2} = \phi \times 0.27 \left(\frac{\alpha_s d}{b_0} + 2\right) \sqrt{f'_c} b_0 d$
   * $V_{c3} = \phi \times 1.06 \sqrt{f'_c} b_0 d$

3. **Flexure and Required Steel:**
   Utilizes internal force equilibrium for rectangular sections subjected to bending, computing required steel area per unit meter ($A_s$) by solving the quadratic equilibrium equation. Results are evaluated against minimum temperature and shrinkage reinforcement requirements:
   $$A_{s,\min} = 0.0018 \, b \, d$$
